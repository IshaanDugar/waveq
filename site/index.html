What’s in a VCD file?

A simulator writes a line each time a signal changes, after a line that says when. Your waveform viewer draws this picture from those lines.

Why not paste the VCD into the chat?

It won’t fit, and the agent would end up guessing.

QuestionRaw VCD in the chatWith WaveQ
SizeMillions of tokens for 12 MBwindow_digest sends a short summary
NamesGuesses the hierarchyresolve_signals finds exact paths
Repeat questionsReads the file againCache reattaches in about 1.5 ms
Many signalsOne scan per signalvalues_at reads eight in under 1 ms

How does it answer so fast?

It reads the dump once into three SQLite tables, then looks things up.

changes
Every transition, in order.
runs
Each stretch a value held. value_at finds yours.
edges
Rises, falls, x and z. Clocks come from here.

Can it find when something happened?

With a clock, find_times reads each signal one tick before the edge, as a flip-flop does.

find_times({
  "conditions": [
    {"signal": "psel", "value": "1"},
    {"signal": "penable", "value": "1"}],
  "clock": "clk"})
cycle 3, edge at 35ns, sampled at 34

What if the answer isn’t there?

It says so, and ok: false tells the agent to stop.

  • value_at("tb.vaild", "16ns")not_found No signal matched 'tb.vaild'
  • value_at("tb.valid", "0.5ns")value_at_failed '0.5ns' is not representable at timescale 1ns
  • changes("tb.valid", "0ns", "500ns")time_out_of_range time 500ns is outside waveform range 0ns..50ns

How do I connect it?

Install once, then add one entry to your MCP client.

terminal
git clone https://github.com/IshaanDugar/waveq
cd waveq
python -m venv .venv
.venv/bin/pip install -e .

Windows: .venv\Scripts\pip install -e .

claude_desktop_config.json
{
  "mcpServers": {
    "waveq": {
      "command": "/path/to/waveq/.venv/bin/python",
      "args": ["-m", "waveq.mcp_server"],
      "cwd": "/path/to/waveq"
    }
  }
}
~/.cursor/mcp.json
{
  "mcpServers": {
    "waveq": {
      "command": "/path/to/waveq/.venv/bin/python",
      "args": ["-m", "waveq.mcp_server"],
      "cwd": "/path/to/waveq"
    }
  }
}
~/.codex/config.toml
[mcp_servers.waveq]
command = "/path/to/waveq/.venv/bin/python"
args = ["-m", "waveq.mcp_server"]
cwd = "/path/to/waveq"
